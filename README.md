# Check Mate · Video Check

Εφαρμογή της ομάδας **Check Mate** (χειριστές challenge στο πρωτάθλημα βόλεϊ) για καταγραφή αγώνων, θέσης (χειριστής / βοηθός), αμοιβής και πληρωμής, με λήψη αναφορών σε CSV (Excel) και HTML/PDF.

- `index.html`: αρχική σελίδα
- `app.html`: η εφαρμογή
- `config.js`: ρυθμίσεις (σύνδεση με Firebase, προεπιλεγμένες αμοιβές)
- `firestore.rules`: ποιοι έχουν πρόσβαση στα κοινά δεδομένα
- `manifest.webmanifest`, `sw.js`, `icons/`: για εγκατάσταση στο κινητό και λειτουργία χωρίς σήμα

---

## 1. Ανέβασμα στο GitHub (≈5 λεπτά)

1. Φτιάξε λογαριασμό στο [github.com](https://github.com) αν δεν έχεις.
2. Πάτα **New repository**. Όνομα π.χ. `checkmate`, επίλεξε **Public**, και πάτα **Create repository**.
3. Στη σελίδα του repo πάτα **uploading an existing file**.
4. Σύρε **όλα** τα αρχεία και τον φάκελο `icons` από το zip. Το κρυφό αρχείο `.nojekyll` είναι προαιρετικό.
5. Πάτα **Commit changes**.
6. Πήγαινε **Settings → Pages**. Στο *Source* διάλεξε **Deploy from a branch**, branch **main**, φάκελος **/ (root)**, και πάτα **Save**.
7. Σε 1–2 λεπτά η σελίδα είναι διαθέσιμη στο `https://<το-username-σου>.github.io/checkmate/`.

Από εκεί η εφαρμογή δουλεύει ήδη σε **τοπική λειτουργία**: τα δεδομένα μένουν μόνο στη συσκευή που τα γράφει. Για κοινή χρήση συνέχισε στο βήμα 2.

> Το GitHub Pages δωρεάν απαιτεί δημόσιο repo. Ο κώδικας είναι δημόσιος, αλλά τα δεδομένα των αγώνων **όχι**. Αυτά μένουν στο Firebase, προστατευμένα με τους κανόνες του βήματος 2.

## 2. Κοινή βάση για όλη την ομάδα (Firebase, δωρεάν)

1. Μπες στο [console.firebase.google.com](https://console.firebase.google.com) και πάτα **Create a project**, π.χ. `checkmate-volley`. Το Google Analytics δεν χρειάζεται.
2. **Build → Firestore Database → Create database**. Τοποθεσία `eur3 (europe-west)` και **production mode**.
3. Στην καρτέλα **Rules**, αντικατέστησε όλο το κείμενο με το περιεχόμενο του `firestore.rules`. Βάλε στη λίστα τα **email Google** όλων της ομάδας και πάτα **Publish**.
4. **Build → Authentication → Get started → Sign-in method → Google → Enable → Save**.
5. Στο **Authentication → Settings → Authorized domains**, πάτα **Add domain** και γράψε `<το-username-σου>.github.io`.
6. **Project settings** (γρανάζι) **→ Your apps → Web (</>)**. Δώσε όνομα και πάτα **Register app**. Αντίγραψε το αντικείμενο `firebaseConfig`.
7. Στο GitHub άνοιξε το `config.js`, πάτα το μολύβι (Edit) και αντικατέστησε το `firebase: null` με τα στοιχεία, όπως δείχνει το παράδειγμα μέσα στο αρχείο. Πάτα **Commit changes**.
8. Άνοιξε την εφαρμογή και πάτα **Σύνδεση με Google**.

Τα στοιχεία του `firebaseConfig` δεν είναι μυστικά. Την πρόσβαση την ελέγχει μόνο η λίστα email στους κανόνες. Για να προσθέσεις ή να αφαιρέσεις κάποιον, αλλάζεις τη λίστα και ξαναπατάς **Publish**.

Αν είχες ήδη γράψει αγώνες σε τοπική λειτουργία, κράτα πρώτα **Αντίγραφο ασφαλείας**. Μετά τη σύνδεση με Firebase τους καταχωρείς ξανά.

## 3. Εγκατάσταση στο κινητό

- **Android (Chrome):** άνοιξε τη σελίδα και πάτα «Εγκατάσταση» στην αρχική ή ⋮ → «Εγκατάσταση εφαρμογής».
- **iPhone (Safari):** Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».

Η εφαρμογή ανοίγει και χωρίς σήμα. Με Firebase, ό,τι καταχωρίσεις offline συγχρονίζεται μόλις επανέλθει η σύνδεση.

## Ενημερώσεις

Όταν αλλάζεις αρχεία, άλλαξε και την έκδοση στην πρώτη γραμμή του `sw.js` (π.χ. `checkmate-v2`), ώστε τα κινητά να πάρουν τη νέα έκδοση.

## Κόστος

Το GitHub Pages είναι δωρεάν. Το Firebase (πρόγραμμα Spark) είναι επίσης δωρεάν για τέτοια χρήση: μια ομάδα με μερικές εκατοντάδες αγώνες τον χρόνο απέχει πολύ από τα όρια.
