# Check Mate · Video Check

Εφαρμογή της ομάδας **Check Mate**, των χειριστών challenge (Video Check) στο πρωτάθλημα βόλεϊ. Σε κάθε αγώνα καταγράφεις ποιος δούλεψε, σε ποια θέση (χειριστής ή βοηθός), την αμοιβή και αν πληρώθηκε. Από εκεί βγάζεις αναφορές και στατιστικά.

- **Εφαρμογή:** https://tsimpinosbv.github.io/checkmate/app.html
- **Αρχική σελίδα:** https://tsimpinosbv.github.io/checkmate/

## 1. Γρήγορη εκκίνηση

**Για νέο μέλος της ομάδας:**

1. Άνοιξε την εφαρμογή από τον σύνδεσμο παραπάνω.
2. Πάτα **«Σύνδεση με Google»** και διάλεξε τον λογαριασμό σου Gmail.
3. Θα δεις το μήνυμα ότι ο λογαριασμός **περιμένει έγκριση**. Ενημέρωσε έναν διαχειριστή.
4. Όταν σε εγκρίνει, ανανέωσε τη σελίδα. Τώρα μπορείς να καταχωρίζεις αγώνες.
5. Προαιρετικά, εγκατάστησε την εφαρμογή στο κινητό ([ενότητα 5](#5-εγκατάσταση-στο-κινητό)).

**Για διαχειριστή:** πήγαινε κατευθείαν στην [ενότητα 4](#4-οδηγός-διαχειριστή).

## 2. Χρήση της εφαρμογής

### Καταχώριση αγώνα
1. Πάτα **«+ Νέος αγώνας»**.
2. Συμπλήρωσε:
   - **Ημερομηνία** και **ώρα**. Η ώρα είναι σε 24ωρη μορφή, π.χ. 18:30.
   - **Γηπεδούχο** και **φιλοξενούμενη** ομάδα.
   - **Διοργάνωση**, π.χ. Volley League Ανδρών, και **γήπεδο** (προαιρετικά).
   - **Άτομο**: το όνομα όπως θα εμφανίζεται στις αναφορές.
   - **Θέση**: *Χειριστής challenge* ή *Βοηθός*.
   - **Αμοιβή** σε €.
   - **Πληρώθηκε** και ημερομηνία πληρωμής, αν έχεις ήδη πληρωθεί.
   - **Σημειώσεις** (προαιρετικά), π.χ. προβλήματα εξοπλισμού ή τρόπος πληρωμής.
3. Πάτα **«Αποθήκευση»**.

Η εφαρμογή θυμάται ομάδες, γήπεδα, διοργανώσεις και την τελευταία αμοιβή ανά θέση, ώστε η επόμενη καταχώριση να γίνεται πιο γρήγορα.

### Πληρωμές
- Στη λίστα, κάθε αγώνας δείχνει **● Εκκρεμεί** ή **✓ Πληρώθηκε**.
- Ένα πάτημα στο κουμπί αλλάζει την κατάσταση. Όταν γίνεται «Πληρώθηκε», μπαίνει αυτόματα η σημερινή ημερομηνία.
- Για άλλη ημερομηνία πληρωμής, άνοιξε τον αγώνα με το ✎.

### Επεξεργασία και διαγραφή
- Πάτα **✎** δίπλα στον αγώνα για αλλαγές.
- Για διαγραφή, άνοιξε τον αγώνα, πάτα **«Διαγραφή»** και επιβεβαίωσε.

### Σύνολα και φίλτρα
- Η σκούρα μπάρα στην κορυφή δείχνει **αγώνες**, **χειριστής / βοηθός**, **σύνολο αμοιβών**, **πληρωμένα** και **εκκρεμή**.
- Τα σύνολα ακολουθούν πάντα τα φίλτρα: **σεζόν** (Ιούλιος–Ιούνιος, π.χ. 2026-27), **μήνας**, **άτομο**, **θέση**, **πληρωμή** και **αναζήτηση**.

### Αναφορές
Οι αναφορές περιέχουν ό,τι δείχνουν τα φίλτρα εκείνη τη στιγμή.
- **⬇ CSV (Excel):** αρχείο που ανοίγει στο Excel με σωστά ελληνικά.
- **⬇ Αναφορά:** σελίδα με σύνολα ανά άτομο και αναλυτική λίστα. Άνοιξέ τη και πάτα **«Εκτύπωση / PDF»** για χαρτί ή PDF.

> Παράδειγμα: για τον μηνιαίο λογαριασμό διάλεξε τον μήνα, «Πληρωμή: Εκκρεμεί», και πάτα «Αναφορά».

### Χωρίς σήμα στο γήπεδο
Η εφαρμογή ανοίγει και χωρίς internet. Ό,τι καταχωρίσεις offline αποθηκεύεται στη συσκευή και συγχρονίζεται μόλις επανέλθει η σύνδεση.

## 3. Χρήστες, ρόλοι και πρόσβαση

### Πώς μπαίνει κάποιος στην εφαρμογή
| Τρόπος | Τι κάνει ο χρήστης | Τι κάνει ο διαχειριστής |
|---|---|---|
| **Αυτο-εγγραφή** | Πατά «Σύνδεση με Google». Μπαίνει ως *Σε αναμονή* και δεν βλέπει τίποτα. | Ανοίγει **Χρήστες** και αλλάζει τον ρόλο του σε *Μέλος* ή *Διαχειριστής*. |
| **Προσθήκη από διαχειριστή** | Απλώς συνδέεται με το Gmail που δόθηκε. Μπαίνει κατευθείαν. | Στο **Χρήστες** γράφει Gmail, όνομα και ρόλο, και πατά **Προσθήκη**. |

> Απαιτείται **λογαριασμός Google** (Gmail ή Google Workspace). Ο χρήστης πρέπει να συνδεθεί με το **ίδιο ακριβώς email** που δήλωσε ο διαχειριστής.

### Ρόλοι
| Ρόλος | Τι βλέπει | Τι μπορεί να κάνει |
|---|---|---|
| **Σε αναμονή** | Μόνο μήνυμα «περιμένει έγκριση» | Τίποτα |
| **Μέλος** | Μόνο **τους δικούς του** αγώνες και τα σύνολά τους | Καταχωρεί, αλλάζει και διαγράφει τους δικούς του αγώνες, σημειώνει πληρωμές, κατεβάζει αναφορές για τους δικούς του |
| **Διαχειριστής** | **Όλους** τους αγώνες όλων, καρτέλα **Στατιστικά** | Όλα όσα κάνει ένα μέλος, για **όλους** τους αγώνες. Επιπλέον αναθέτει αγώνα σε χρήστη και διαχειρίζεται χρήστες (έγκριση, ρόλοι, αποκλεισμός, αφαίρεση) |
| **Αποκλεισμένος** | Μήνυμα «δεν έχει πρόσβαση» | Τίποτα |

### Μόνιμοι διαχειριστές και πρόσθετοι διαχειριστές
Υπάρχουν δύο είδη διαχειριστών:

- **Μόνιμοι διαχειριστές:** τα email τους είναι γραμμένα στους κανόνες ασφαλείας του Firebase, στη συνάρτηση `owners()`. Είναι **πάντα** διαχειριστές. Κανείς δεν μπορεί να τους υποβιβάσει ή να τους κλειδώσει έξω από την εφαρμογή, ούτε κατά λάθος.
- **Πρόσθετοι διαχειριστές:** ορίζονται μέσα από την εφαρμογή (Χρήστες → ρόλος *Διαχειριστής*).

| | Μόνιμος | Πρόσθετος |
|---|---|---|
| Βλέπει όλους τους αγώνες και τα στατιστικά | ✓ | ✓ |
| Αλλάζει και διαγράφει οποιονδήποτε αγώνα | ✓ | ✓ |
| Διαχειρίζεται χρήστες, και άλλους διαχειριστές | ✓ | ✓ |
| Μπορεί να υποβιβαστεί ή να αφαιρεθεί από άλλον διαχειριστή | ✗ | ✓ |
| Πρόσβαση στην κονσόλα Firebase και στο GitHub | Μόνο ο κάτοχος των λογαριασμών | ✗ |

> **Προσοχή:** ένας πρόσθετος διαχειριστής έχει **πλήρη** δικαιώματα μέσα στην εφαρμογή. Δώσε αυτόν τον ρόλο μόνο σε άτομα που εμπιστεύεσαι. Κανείς δεν μπορεί να αλλάξει τον δικό του ρόλο.

## 4. Οδηγός διαχειριστή

### Έγκριση νέου χρήστη
1. Το κουμπί **Χρήστες** δείχνει πορτοκαλί αριθμό όταν κάποιοι περιμένουν.
2. Ανοίξέ το. Όσοι περιμένουν εμφανίζονται πρώτοι, με πορτοκαλί φόντο.
3. Άλλαξε το **Σε αναμονή** σε **Μέλος** (ή **Διαχειριστής**). Η αλλαγή αποθηκεύεται αμέσως.
4. Πες στον χρήστη να ανανεώσει τη σελίδα.

### Προσθήκη χρήστη από πριν
1. **Χρήστες** → συμπλήρωσε **Gmail**, **Όνομα**, **Ρόλο** → **Προσθήκη**.
2. Στείλε του τον σύνδεσμο της εφαρμογής.

### Αλλαγή ρόλου, αποκλεισμός, αφαίρεση
- **Αλλαγή ρόλου:** από τη λίστα επιλογών δίπλα στον χρήστη.
- **Αποκλεισμός:** ρόλος **Αποκλεισμένος**. Ο χρήστης δεν μπορεί πια να μπει, αλλά οι αγώνες του μένουν.
- **Αφαίρεση:** σβήνει τον χρήστη από τη λίστα. Αν συνδεθεί ξανά, θα εμφανιστεί πάλι ως *Σε αναμονή*. Για να μη μπορεί να ξαναμπεί, προτίμησε τον **αποκλεισμό**.

### Στατιστικά
- Πάνω από τη λίστα αγώνων υπάρχει η επιλογή **Αγώνες | Στατιστικά**.
- Τα **Στατιστικά** δείχνουν πίνακες **ανά άτομο** και **ανά μήνα**: αγώνες, πόσες φορές ως χειριστής και ως βοηθός, σύνολο, πληρωμένα και εκκρεμή.
- Ακολουθούν τα φίλτρα. Για τη σεζόν, διάλεξε π.χ. «2026-27».

### Ανάθεση αγώνα σε χρήστη
Όταν ένας διαχειριστής καταχωρεί ή αλλάζει αγώνα, εμφανίζεται το πεδίο **«Λογαριασμός χρήστη»**. Εκεί διαλέγεις σε ποιο μέλος ανήκει ο αγώνας, ώστε να τον βλέπει στη δική του λίστα. Οι αγώνες «Χωρίς λογαριασμό» φαίνονται μόνο στους διαχειριστές.

### Αλλαγή των μόνιμων διαχειριστών
Γίνεται μόνο από την κονσόλα του Firebase:
1. https://console.firebase.google.com → project **checkmate** → **Firestore Database** → **Rules**.
2. Στη γραμμή `function owners() { return [ ... ]; }` πρόσθεσε ή αφαίρεσε email. Γράψε τα σε μικρά γράμματα, μέσα σε `'...'`, χωρισμένα με κόμμα.
3. Πάτα **Publish**. Η αλλαγή ισχύει μέσα σε περίπου 1 λεπτό.

## 5. Εγκατάσταση στο κινητό

Η εφαρμογή εγκαθίσταται από τον browser, χωρίς app store. Αποκτά δικό της εικονίδιο και ανοίγει σε πλήρη οθόνη.

**Android (Chrome)**
1. Άνοιξε https://tsimpinosbv.github.io/checkmate/ στο Chrome.
2. Πάτα **«Εγκατάσταση»** στην αρχική σελίδα, ή μενού **⋮** → **«Εγκατάσταση εφαρμογής»** / **«Προσθήκη στην αρχική οθόνη»**.

**iPhone / iPad (Safari)**
1. Άνοιξε τη σελίδα στο **Safari**. Σε άλλους browser στο iPhone η επιλογή μπορεί να λείπει.
2. Πάτα **Κοινοποίηση** (τετράγωνο με βέλος προς τα πάνω).
3. **«Προσθήκη στην οθόνη Αφετηρίας»** → **«Προσθήκη»**.

**Υπολογιστής (Chrome / Edge):** εικονίδιο εγκατάστασης στη γραμμή διευθύνσεων, ή απλώς πρόσθεσε τη σελίδα στους σελιδοδείκτες.

## 6. Τεχνική ρύθμιση (GitHub & Firebase)

> Αυτά έχουν **ήδη γίνει** για το Check Mate. Τα κρατάμε για αναφορά, ή αν χρειαστεί να στηθεί από την αρχή.

### 6.1 GitHub Pages (φιλοξενία)
1. Repository: `tsimpinosbv/checkmate`, δημόσιο.
2. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
3. Η εφαρμογή σερβίρεται στο `https://tsimpinosbv.github.io/checkmate/`.

### 6.2 Firebase (βάση δεδομένων και σύνδεση)
Project: **checkmate** (ID `checkmate-33472`), δωρεάν πρόγραμμα **Spark**.

1. **Firestore Database** → *Create database* → Standard edition → τοποθεσία **eur3 (Europe)** → **production mode**.
2. **Firestore → Rules:** επικόλλησε το περιεχόμενο του `firestore.rules`. Στη συνάρτηση `owners()` βάλε τα email των μόνιμων διαχειριστών. Πάτα **Publish**.
3. **Authentication** → *Get started* → **Sign-in method → Google → Enable**. Όρισε δημόσιο όνομα «Check Mate» και email υποστήριξης, και πάτα **Save**.
4. **Authentication → Settings → Authorized domains → Add domain →** `tsimpinosbv.github.io`.
5. **Project settings → Your apps → Web (</>)** → όνομα «Check Mate» → *Register app*.
6. Αντέγραψε το `firebaseConfig` στο `config.js`, στο πεδίο `firebase: { ... }`.

### 6.3 Δομή δεδομένων
- `users/{email}`: `{ email, name, role: pending | member | admin | blocked, createdAt }`
- `matches/{id}`: `{ date, time, home, away, comp, venue, person, role: op | as, fee, paid, paidDate, notes, ownerEmail, createdAt, updatedAt, createdBy, updatedBy }`

### 6.4 Τοπική λειτουργία (χωρίς Firebase)
Αν στο `config.js` γράψεις `firebase: null`, η εφαρμογή δουλεύει χωρίς σύνδεση και κρατά τα δεδομένα μόνο στη συσκευή. Σε αυτή τη λειτουργία υπάρχουν κουμπιά **Αντίγραφο ασφαλείας / Επαναφορά** (αρχείο JSON). Αγώνες που είχαν γραφτεί τοπικά μεταφέρονται στην κοινή βάση με το κουμπί **«Μεταφορά στην κοινή βάση»** μετά τη σύνδεση.

### 6.5 Προεπιλεγμένες αμοιβές
Στο `config.js`: `defaultFees: { op: 40, as: 25 }`. Τα ποσά είναι σε € για χειριστή και βοηθό. Η εφαρμογή τα προτείνει σε κάθε νέο αγώνα.

## 9. Ασφάλεια, απόρρητο και κόστος

- Ο **κώδικας** είναι δημόσιος στο GitHub. Τα **δεδομένα** (αγώνες, αμοιβές, χρήστες) **δεν** είναι δημόσια: μένουν στο Firebase και τα προστατεύουν οι κανόνες ασφαλείας.
- Τα στοιχεία στο `config.js` (apiKey κ.λπ.) **δεν είναι μυστικά**, γιατί έτσι λειτουργεί το Firebase στον browser. Την πρόσβαση την ελέγχουν μόνο οι κανόνες και οι ρόλοι.
- Τα email των μόνιμων διαχειριστών υπάρχουν **μόνο** στην κονσόλα του Firebase. Στο αρχείο `firestore.rules` του GitHub υπάρχει μόνο ένα παράδειγμα (`to-email-sou@gmail.com`).
- **Κόστος:** GitHub Pages δωρεάν, Firebase Spark δωρεάν. Για μια ομάδα με μερικές εκατοντάδες αγώνες τον χρόνο, η χρήση απέχει πολύ από τα δωρεάν όρια.
- **Αντίγραφα ασφαλείας:** το δωρεάν πρόγραμμα δεν περιλαμβάνει αυτόματα backup. Κατέβαζε περιοδικά **CSV** με όλους τους αγώνες, π.χ. στο τέλος κάθε μήνα και κάθε σεζόν.
